巨鹏软件客户端 · 使用手册

窗口标题「业务小助手」 · 对接巨鹏 AIF / DCP 平台的桌面消息与协作终端

桌面客户端Windows / macOS 消息 · 待办 · 网盘 · AITauri 2 构建

1 软件简介

巨鹏软件客户端（窗口标题显示为「业务小助手」，托盘名称随产品形态变化：运维为「运维小助手」、一表通为「一表通小助手」）是一款基于 Tauri 2 技术栈开发的轻量级桌面应用。它把浏览器端的巨鹏平台（51yunwei.com.cn 的 AIF 运维 / DCP 一表通）封装为本地常驻客户端，提供比网页更及时的消息提醒、桌面级集成与本地数据持久化。

它能做什么

🔔
消息提醒后台轮询，新消息弹窗+声音+托盘闪烁，支持系统通知与「稍后提醒」
✅
待办管理待办面板、超时升级提醒、每日定时摘要
🌐
多标签页 WebView在桌面壳内打开任意平台页面，像浏览器一样多标签
📁
网盘传输个人空间浏览、批量上传/下载/删除/同步
🤖
AI 助手直达 AIF / DCP 已授权智能体会话
📌
迷你速览条屏幕右缘常驻小窗，悬停即看未读与待办（Windows）
产品形态 客户端同时支持两套产品：运维（AIF） 与 一表通（DCP）。两者会话隔离、数据不互通。AIF 才显示「运维」导航与告警；「助手」智能体列表随当前账号已授权情况加载。可在「我的 → 常用入口」中保存两套入口并一键切换。

2 安装与启动

环境要求

  • Windows Windows 10 / 11（x64 或 arm64）。安装包为 .msi 或 -setup.exe（NSIS）。
  • macOS macOS 11+，提供通用包（.dmg，同时支持 Apple Silicon 与 Intel）。

安装步骤

  1. 从分发渠道获取安装包（企业内部分发或 GitHub Releases 的 .dmg / .msi）。
  2. Windows 双击安装包按向导完成安装；macOS 打开 .dmg 将应用拖入「应用程序」。
  3. 首次启动会进入登录页（见第 3 章）。
macOS 浏览器下载 / 未公证提示 若安装包未经 Apple 公证，在他人 Mac 上首次打开会被 Gatekeeper 拦截（「无法验证开发者」）。自用可绕过：在终端执行 xattr -cr /Applications/巨鹏软件客户端.app，或在 Finder 中右键「打开」。正规分发需配置 Apple 开发者证书做签名与公证。

启动后

客户端最小化到系统托盘常驻运行。点击托盘图标（或自定义全局快捷键）即可唤起主窗口。关闭主窗口默认并非退出程序，而是隐藏到托盘；需从设置或托盘菜单的「退出」彻底关闭。

3 登录与多入口

账号密码登录

首次使用或退出登录后，进入登录页：

  • 服务器地址：填写平台站点根地址，例如 https://51yunwei.com.cn（不含 /AIF 后缀）。
  • 账号 / 密码：平台账号与密码。
  • 图形验证码：连续输错密码 3 次后触发图形验证码，点击图片可刷新。验证码正确输入后方可登录。
服务器地址与产品路径 设置中的「服务器设置」折叠区可展开修改站点根地址与产品路径，建议在登录前先确认正确（首次使用需初始化 URL / 产品后再登录）。

常用入口（多账号 / 多项目凭据管理）

进入「我的 → 常用入口」可保存多组服务器入口，每组包含：项目形态（运维 / 一表通）、站点地址、账号、密码、备注。密码采用国密 SM4 加密后存储于本地数据库（不是明文）。

  • 主键为「项目 + 网址 + 账号」，同一项目同一网址下可保存多个账号。
  • 选中历史入口会自动带出凭据并登录，成功后自动刷新数据。
  • 支持「保存并登录」「保存」「删除该入口」。

自动登录

在「设置 → 自动登录」开启后，启动时用已存凭据静默登录（若遇验证码则仍会弹出登录窗）。凭据来自系统钥匙串（Windows 凭据管理器 / macOS Keychain），重装系统或更换设备需重新登录一次。

多入口切换（顶栏）

开启「设置 → 多入口切换」后，全屏模式顶栏出现「切换入口」按钮，可在已保存的多个账号（同项目 + 网址多账号）间一键切换；切换会保存当前设置、切换 base_url / 产品、登录成功后整版刷新数据。失败时自动回滚，避免轮询打到错误地址。

当前角色切换

多角色账号可在「我的 → 当前角色」下拉切换，切换后立即生效。

心跳与会话保活

客户端按「我的 → 心跳间隔」（默认 60 秒，范围 30 秒 ~ 60 分钟）与平台同源保活；会话失效时自动用保存的入口凭据重登录，无需反复手动登录。

5 消息

客户端按心跳/轮询间隔后台拉取新消息，并在「消息」导航中展示列表（标题、正文摘要、接收时间）。每条未读消息有角标计数。

新消息的提醒方式

  • 弹窗：收到新消息以桌面弹窗提示（非紧急消息默认不闪烁托盘，详见托盘章节）。
  • 提示音：按设置播放「叮 / 风铃 / 水滴」三种音效之一。
  • 系统通知：发出系统级通知，点击通知可跳回对应消息并标记已读。
  • 托盘角标 / 闪烁：托盘图标显示未读数；紧急场景闪烁提示。

稍后提醒

在消息行的「稍后」按钮，可将这条提醒推迟 30 分钟后再次发送系统通知（不立即打开消息）。同一消息重复点击「稍后」会顺延而非叠加。计划持久化在本地，重启后恢复；超期 24 小时的提醒自动丢弃。

转已读

点击任意未读消息行即标记该条为已读（角标与列表样式同步更新）并打开其链接页面。系统通知/弹窗点击跳转也会按 URL 自动转已读。

免打扰与过滤

设置效果
勿扰时段时段内新消息只计未读角标：不弹窗、不响铃、不闪托盘（支持跨午夜，如 22:00 ~ 08:00）
消息静音关键词标题或正文命中任一关键词的消息不弹窗、不响铃（未读角标照常）。多个关键词用逗号分隔

6 待办

「待办」导航展示待办事项面板，每条事项可包含多条待办条目（角标按其合计口径统计）。点击事项可直达办理页。

待办超时升级提醒

在「设置 → 待办超时提醒」设定天数（如 3 天）后，事项在本地可见超过该天数仍未办结时，弹一次升级提醒并闪托盘（每个事项只提醒一次），帮助避免遗漏长期挂起的任务。

每日定时摘要

开启「设置 → 每日定时摘要」并指定时间后，每天固定时刻推送一条汇总：待办 N 件未办结 + 今日新消息 M 条，形成每天看一眼的习惯锚点。

托盘待办速览

右键托盘弹出的菜单中段为「待办速览」，列出未办结事项前 5 件，点击任一项即弹出面板并直达其办理页（详见第 15 章）。

7 运维（AIF）

仅运维（AIF）产品显示 此导航在一表通（DCP）下自动隐藏。

「运维」模块聚合平台的应用中心与告警信息：

  • 应用列表：按分组展示运维应用，支持搜索。
  • 告警状态：状态为「告警」的应用会以红色高亮显示其告警事件文本。
  • 迷你速览条联动：在迷你条（Windows）上，有告警的应用会亮红并显示数量，点击直达应用页。

8 文档 / 空间

文档

「文档」导航浏览平台文档库内容（知识库文章等），在桌面壳内以网页形式呈现与浏览。

空间

「空间」导航展示你有权限的协作空间，便于在客户端内直接访问团队空间内容。

与「网盘」的区别 「文档 / 空间」是浏览平台已有内容；「网盘」章节的传输功能才是把本地文件上传到个人空间 / 从空间下载到本地的双向文件管理。

9 网盘（特色功能）

「网盘」模块把平台的个人空间（以及你有权限的空间）变成一个桌面文件管理器：浏览目录树、批量上传、下载、删除、并可将本地目录与空间同步。

9.1 浏览目录

  • 左侧为目录树（subject 目录节点），点击目录展开其下文件与子目录（扁平列表）。
  • 文章节点分两类：FILE 型附件（真实文件）与在线文档（DOC / RICHTEXT / MARKDOWN / EXCEL 等）。
  • 个人空间的 spaceId 由客户端自动从平台页面注入的变量识别并缓存。

9.2 上传

  • 在网盘页选择目标目录，将本地文件加入上传队列，批量上传。
  • 单文件上限 100 MB（平台限制）。超过会在上传前拦截并提示。
  • 类型白名单：仅允许常见办公 / 文本 / 图片等类型（如 doc/docx/xls/xlsx/ppt/pptx/pdf/zip/png/jpg/mp4/md/txt/json/xml/html 等），非白名单类型在上传前即拦截，不会发起请求。
  • 同名处理：目标目录已存在同名 FILE 附件时走「替换」（保留文章 id 替换文件内容）；否则新建登记，不会产生重复附件。单次登记上限 20 个文件/批。
  • 上传进度在网盘页以任务条展示（每文件成功/失败状态）。

9.3 下载

  • 勾选要下载的文件/目录，选择本地目标文件夹，批量下载。
  • 下载按文章类型分流：
    类型下载产物
    FILE 附件直连下载原始文件（保留原格式/扩展名）
    MARKDOWN导出为 .md（保留 UTF-8 原文）
    DOC / RICHTEXT服务端转换为 .docx
    EXCEL / COLLEXCEL导出为 .xlsx（原始表格）
  • 手动下载默认防冲突重命名（同名文件追加 (1) / (2)）；网盘「同步」模式则直接覆盖写。
  • 若服务端返回错误页（如无下载/导出权限），该文件会被标记为失败并提示，不污染本地。

9.4 删除

  • 在网盘页可删除选中的文件（文章）与目录（subject）。
  • 删除前请确认：在线文档（非 FILE 文章）需在前端排除，删除命令只接收可删除的 id。
  • 删除结果汇总显示成功/失败数量，便于核对。
删除是高风险的不可逆操作 删除会直接作用于平台空间。操作前请逐项确认要删除的文件与目录；建议重要资料先下载备份（见第 18 章）再删除。

9.5 资源管理器右键「上传到协作空间」（Windows 特色）

在「设置 → 资源管理器右键上传菜单」开启后，Windows 资源管理器对文件的右键菜单（Win11 在「显示更多选项」二级菜单中）会出现 「上传到协作空间」。选中一个或多个文件，点击即可把它们送入客户端的上传队列。

  • 采用系统注册表（HKCU，无需管理员权限）注册，免安装驱动。
  • 支持多选文件：对每个选中文件逐个透传，保证全部进入上传队列（规避 Win11 部分环境 %* 不展开问题）。
  • 上传目标为网盘页上次使用的目录。
  • 开关即注册/注销，新开右键菜单生效；关闭后从注册表移除。
适用范围此右键菜单仅 Windows 支持；macOS 无对应系统级右键扩展，请使用网盘页内的上传功能。

10 快捷功能

「快捷」导航以网格形式展示平台（B/S）配置的快捷入口（图标 + 名称）。点击任一入口即在标签页打开对应页面，相当于把常用功能钉在客户端首页。

迷你速览条上的「快捷」按钮悬停也会浮出同一份快捷方式列表，无需打开主窗口即可快速跳转。

11 助手（AI）

「助手」导航列出当前账号已授权的 AI 智能体（名称、描述、图标）。点击任一智能体即打开其会话页，开始对话。

  • 智能体列表随接口缓存（5 分钟 TTL），点击顶栏「刷新」或助手页的刷新按钮可强制刷新。
  • 未授权任何智能体时显示「当前账号没有已授权的智能体」。
  • 顶栏的 AI 问答 按钮则直接打开平台 AI 问答入口页（与智能体会话页同一体系）。
  • 迷你速览条的「助手」按钮悬停可浮出智能体列表，点击直达会话。

12 我的

「我的」页面是账号与本地配置中枢：

  • 账号信息：显示当前用户姓名、角色、账号；多角色可在「当前角色」下拉切换。
  • 重启后恢复标签页：开启后，下次进入全屏模式自动恢复上次打开的标签页（最多 8 个；休眠的标签点击后再加载，不拖慢启动）。
  • 心跳间隔：与会话保活同源，默认 60 秒，可在 30 秒 ~ 60 分钟间调整。
  • 常用入口：保存 / 切换 / 删除多组服务器入口（详见第 3 章）。
  • 设置入口：所有开关与偏好设置集中在此（详见第 17 章）。

13 多标签页与命令面板

多标签页

开启顶栏「多标签页」后，每点击一个页面都会新开一个标签页；关闭则只保留首个标签，点击页面仅更新该标签。标签区位于内容区顶部：

  • Ctrl + T 新建空白标签页（全屏模式）。
  • Ctrl + W 关闭当前标签页。
  • 标签长时间（60 分钟）未激活会进入「休眠」状态，点击重新加载，节省资源。

命令面板（快速跳转）

按 Ctrl + K（macOS 同）打开命令面板，输入即搜：

  • 功能（如「消息」「网盘」「设置」）
  • 待办事项（按标题匹配，回车直达办理页）
  • 消息（按内容匹配）
  • 常用入口（按名称匹配，回车打开）

这是绕过层层菜单、直达目标的最快方式。

14 迷你速览条（特色功能）

仅 Windows 在「设置 → 迷你速览条」开启后，屏幕右缘会常驻一条细长小窗（macOS 不提供此功能，对应开关隐藏）。

它能做什么

  • 常显未读消息数与待办数：有内容时高亮（红），无内容时置灰，一眼可辨。
  • 悬停即展开预览卡：显示待办未办结 Top5、最近消息、告警应用（AIF）、可用智能体、快捷方式。
  • 点击预览卡中的任一行 / 按钮，直接唤起主窗口并跳转到对应页面（消息 / 待办 / 应用 / 智能体会话 / 快捷功能 / 面板），无需手动打开主窗。
  • 悬停「助手」/「快捷」按钮可把卡片整体切换为对应列表。
  • 速览条带「关闭」按钮，关闭后状态记忆，重启恢复。
使用场景 把主窗口收起、只留迷你条，既能随时看到有没有新消息/待办，又不被大窗口打扰；需要时悬停或点击即可直达，是「常驻但不占地方」的提醒方式。

15 托盘与鼠标右键（特色功能）

系统托盘

客户端最小化后以托盘图标常驻。托盘行为是桌面集成的关键：

操作效果
左键单击托盘右下角弹出主面板并聚焦（不自动收起）。同时视为「新消息已阅」：停止托盘闪烁
右键单击托盘弹出右键菜单（见下）
鼠标悬停托盘按系统深浅模式刷新菜单图标（主题切换兜底）

托盘右键菜单

右键托盘图标弹出菜单，包含：

  • 打开面板：显示并聚焦主窗口。
  • 刷新数据：立即触发一次后台轮询，拉取最新消息/待办。
  • 设置：打开主窗口并跳到设置页。
  • 退出：彻底关闭程序（区别于「关闭窗口 = 隐藏到托盘」）。
  • 待办速览（动态段）：菜单中段列出未办结事项前 5 件，标注「待办速览（N 件未办）」；点击其中任一项即弹出面板并直达其办理页。
菜单主题自适应 托盘菜单图标随系统浅色/深色模式自动切换（墨黑 / 近白双套配色）。macOS 会忽略菜单项的小图标（系统限制），功能不受影响。

资源管理器右键（Windows）

即第 9.5 节的「上传到协作空间」——在文件管理器右键上传文件到网盘。这是另一处「鼠标右键」集成，把桌面文件无缝送进平台个人空间。

16 全局快捷键

在「设置 → 快捷键」中可自定义一个系统级热键，用于一键显示 / 隐藏主窗口（即使客户端在后台也能唤起）。

  • 点击输入框后按下组合键即录入；组合必须包含 Ctrl / Alt / Win 之一（仅 Shift+字母不算有效热键）。
  • 按 Esc 或点击「清除」可注销快捷键。
  • 行为：主窗口「可见且拥有焦点」时按下→隐藏到托盘；否则→弹出并抢前台。
  • 若提示注册失败，通常是该组合已被其他程序占用，换一个即可。

18 数据备份与恢复

客户端的所有本地数据（设置、消息/待办历史、加密后的账号保险库、SM4 密钥等）都存放在一个本地数据库文件中。

18.1 数据存放在哪里

核心数据目录由应用标识符 cn.aif.desktopclient 决定：

系统路径
WindowsC:\Users\<你的用户名>\AppData\Local\cn.aif.desktopclient\
macOS~/Library/Application Support/cn.aif.desktopclient/

Windows 的 AppData\Local 是隐藏文件夹，需在资源管理器勾选「显示隐藏的项目」才能看到。

该目录内关键文件：

文件内容是否需备份
aif_client.db核心数据库：设置、消息/待办历史、账号保险库（SM4 加密）、密钥✅ 必须
icon_cache/快捷入口图标本地缓存否（可重建）
captured_requests.json登录探针调试记录否
logs/巨鹏软件客户端.log运行日志否（排查用）
登录凭据不在该目录 会话 cookie / JSESSIONID 存放在系统钥匙串（Windows 凭据管理器 / macOS Keychain），不在应用数据目录。会话有过期时效，重装后重新登录一次即可恢复，因此备份凭据意义不大。网盘下载的文件也不在此目录，而是你下载时自选的保存位置。

18.2 如何备份

核心是复制整个应用数据目录（重点是其中的 aif_client.db）。

Windows（PowerShell，先完全退出软件）

Copy-Item "$env:LOCALAPPDATA\cn.aif.desktopclient" "D:\Backup\aif-client-backup" -Recurse -Force

macOS（终端）

cp -R ~/Library/Application\ Support/cn.aif.desktopclient /Volumes/Backup/aif-client-backup
备份前务必先退出软件 从托盘菜单「退出」彻底关闭程序，否则数据库可能正在写入，复制出来会损坏。想更稳妥也可只复制单个 aif_client.db 文件——它已包含全部设置、消息、账号保险库。

18.3 如何恢复

  1. 完全退出软件（托盘「退出」）。
  2. 把备份的 cn.aif.desktopclient 目录整体覆盖回原路径（Windows 为 AppData\Local\cn.aif.desktopclient\，macOS 为 ~/Library/Application Support/cn.aif.desktopclient/）。
  3. 重新启动软件。
  4. 重新登录一次：因为钥匙串里的会话没备份、已过期，本地设置/历史/账号保险库会从 aif_client.db 自动加载，但需刷新会话。
一句话总结 备份 = 关软件 → 拷 AppData\Local\cn.aif.desktopclient 整个文件夹；恢复 = 覆盖回去 + 重新登录。消息/待办历史、设置、保存的账号密码（加密在库内）全部在 aif_client.db 中。

19 常见问题

Q1：关闭主窗口后程序还在运行吗？

是的。关闭窗口只是隐藏到托盘常驻；需从托盘菜单「退出」或设置页「退出程序」才彻底关闭。

Q2：点了托盘/快捷键没反应，窗口不弹出？

Windows 下从托盘或全局热键首次唤起时，本进程可能没有前台权限，系统会拒绝置顶。客户端已用「强制置顶一次再还原」的方式处理，通常第一次即可到最前；若仍异常，尝试先点击一下任务栏再试，或重启客户端。

Q3：网盘上传提示「非白名单类型」或「超过 100MB」？

平台限制单文件 ≤100MB，且只允许常见办公/文本/图片等类型。请压缩分包或改用平台网页上传大文件/非常见类型。

Q4：网盘下载的在线文档变成了 .docx / .md / .xlsx？

这是正常的：在线文档（DOC/RICHTEXT→DOCX、MARKDOWN→MD、EXCEL→XLSX）由服务端转换导出；只有 FILE 附件才保留原始格式。

Q5：macOS 没有迷你速览条？

对，迷你速览条仅 Windows 提供（macOS 开关隐藏且不创建窗口）。macOS 可用托盘 + 全局快捷键满足日常唤起。

Q6：重装系统 / 换电脑后历史消息还在吗？

不在——数据在本地应用目录，不随账号云端同步。请用第 18 章方法提前备份 aif_client.db；迁移后覆盖回新机器的对应目录即可找回（会话需重新登录）。

Q7：右键「上传到协作空间」在哪里？

需先在设置开启「资源管理器右键上传菜单」（仅 Windows）；Win11 在文件右键「显示更多选项」二级菜单中。上传目标为网盘页上次使用的目录。

本手册基于巨鹏软件客户端（Tauri 2）实际功能编写，适用于 Windows 与 macOS 桌面端。如功能随版本更新变化，以软件实际界面为准。
